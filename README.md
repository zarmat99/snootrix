# SNOOTRIX Face Editor

Draw faces for a protogen LED visor (two 64×32 panels), watch them live on a 3D head, talk and see the mouth move, boop the snoot, and share your face as a link or an image.

**Open it: https://zarmat99.github.io/snootrix/**

- Free, no account.
- Everything runs in your browser: no cookies, no analytics, no requests to other sites. The microphone is analysed on your device and never recorded or sent anywhere. Saved faces stay in your browser.
- The 3D head is an original concept design, the same as in the SNOOTRIX video. No AI-generated images.

SNOOTRIX is a plug & play LED visor controller in development. This editor is meant to become the face editor of the real board. Waitlist: https://tally.so/r/eqdb1k?src=github

This repository holds the built site, published with GitHub Pages. Third-party code (three.js and the meshoptimizer decoder, both MIT) is listed in `THIRD-PARTY-NOTICES.txt`.
